## Nasazení (GitHub Pages)

Web běží jako čistě statická stránka (`index.html` + `style.css`) přes **GitHub Pages**:
- V nastavení repozitáře na GitHubu (**Settings → Pages**) nastav **Branch: `main`** a složku **`/ (root)`**.
- Vlastní doménu `www.zkusmo.cz` určuje soubor [`CNAME`](CNAME).
- Pro lokální zobrazení na počítači stačí přímo otevřít soubor [`index.html`](index.html) v prohlížeči.
